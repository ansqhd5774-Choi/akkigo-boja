# 출처 경고 후속 조치

## 완료한 범위

- 467개 초기 관찰 중 경고 151건 전부에 조치와 다음 검토일을 지정했다. 원래 경고를 삭제하지 않았다.
- 기존·이번 직접 검토 기록 23건, 추가 브라우저 렌더링 관찰 84건을 저장했다. 렌더링 관찰은 개별 쿠폰 발행·현재 사용 성공 증거가 아니다.
- PDF를 빈 HTML로 판단하는 오탐을 수정했다. 실제 PDF 응답은 HTTP 200 / application/pdf로 확인했으며 PDF 텍스트는 미검증이다.
- 정상 본문의 reCAPTCHA 안내 문구가 접근 차단으로 분류되는 오탐을 수정했다. GoMoWorld 두 페이지와 Warframe 공식 등록 화면에서 직접 확인했다.
- 재점검 시 수동 검토를 이전 관찰 날짜·해시와 함께 이력으로 보존한다. 오래된 검토를 새 본문의 확인 결과로 재사용하지 않는다.
- 넥슨 50CUBECOUPON 공식 원문은 브라우저에서 확인했다. 2026-09-16 게시, 미라클 큐브 50개, 2026-10-07 23:59 종료이며 기존 원고와 일치하여 재발행하지 않았다.
- FC Mobile 공식 쿠폰 주소의 로그인 도메인 이동을 확인했다. 로그인·쿠폰 입력은 수행하지 않았다.

## 미완료와 다음 처리

- 접근 실패 42건: 기존 관찰·경고를 유지하고 예약된 backoff로 재확인한다. 실패를 쿠폰 만료로 바꾸지 않는다.
- 삭제된 원문 2건: 역사 인용을 유지한다. 같은 내용을 입증할 대체 원문 확보 전에는 회복 완료로 처리하지 않는다.
- PDF 텍스트 및 렌더링 관찰의 개별 주장·쿠폰 근거 확인은 별도 미완료다. 화면 텍스트가 있다는 이유만으로 완료 처리하지 않는다.
- 249개 출처 미확인 쿠폰 기록은 그대로 미확인이다. 전체 63개 운영 항목의 완료 보고가 아니다.
