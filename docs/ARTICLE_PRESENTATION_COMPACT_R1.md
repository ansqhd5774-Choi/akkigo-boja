# 글 작성·수정 시 필수 표현 규칙 R1

2026-10-09 사용자 11개 지적 반영. 기간 탭 양식 결정은 별도 공통 계약을 따르며 상태별 링크를 새 탭 양식으로 간주하지 않는다.

- 제목·소제목은 짧게 쓴다. 예: `최신`, `지난 기록`, `추가 후보`, `입력 방법`. 게시 날짜 의미를 제목에 길게 풀어 쓰지 않는다.
- 상단에는 코드·보상·종료 시각·핵심 제한만 짧게 표시한다. 출처 설명과 조사 방법은 반복하지 않는다.
- 검색 설명은 별도 검색 설명 설정에 쓴다. 검색에만 보이게 하려는 문장을 본문에 숨김 텍스트로 넣지 않는다. 검색 설명이 반드시 그대로 검색 결과에 나오는 것은 아니다.
- 최초 공식 게시일·만료일·원문 링크는 표에 보존한다. 만료나 미확인 상태를 가리지 않는다.
- 보충 설명은 `renderArticleInfo`의 클릭·터치·키보드 가능한 ⓘ에 넣는다. hover 전용 tooltip을 쓰지 않는다.
- 펼침 목록은 연도·개수와 회전 화살표로 표시한다. `펼쳐보기` 문구를 붙이지 않는다.
- CSS content에 유니코드 화살표를 넣지 않는다. Blogger 저장 과정에서 엔티티 문자열로 변환될 수 있으므로 CSS 테두리 또는 SVG로 그린다. 안내 아이콘은 영역 오른쪽 상단에 배치하고 SVG 선 굵기 2.4를 사용한다. 아이콘 외부 장식 테두리는 제거한다.
- 공유 아이콘은 복사 왼쪽에 둔다. 기기 공유가 지원되면 기본 공유창, 미지원이면 코드와 현재 글 주소를 복사한다. 공유 동작은 쿠폰 복사 완료 상태나 사용 완료로 기록하지 않는다.
- 이동 버튼은 충분한 간격·44px 클릭 영역·명확한 색·키보드 초점을 제공한다. 단순 앵커 링크를 활성 탭인 것처럼 설명하지 않는다.
- 코드·보상·기한이 이미 상단/표에 있으면 바로 아래에서 같은 내용을 반복하지 않는다.
- 신규 글과 UI를 변경하는 글은 `source.presentationVersion="compact-r1"` 및 `data-ncp-presentation="compact-r1"`을 포함하고 `validateArticlePresentation`을 통과해야 한다. 기존 글은 일괄 재작성하지 않는다.
- 자동 검사 외에 변경 화면의 PC·모바일 렌더링을 확인한다. 정상 데이터 갱신에 매번 화면 검사를 추가하지 않는다.

검사 연결: `tools/validate-article-draft.mjs` 및 Worker `src/articles.js`. `tests/article-presentation.test.js`는 고정 기존 글 목록 밖의 모든 신규 게임 원고에 버전 선언을 요구한다. 개별 양식의 기간 탭 통합은 후속 공통 생성기 작업으로 남아 있다. 공통 모듈은 `src/article-presentation.js`이다.
