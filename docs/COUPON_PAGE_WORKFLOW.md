# 게임 쿠폰 페이지 생성·발행 기준

- 본문은 `src/game-period-article.js` 공통 렌더러를 사용한다. 데이터만 변경하고 글마다 CSS나 더 보기 스크립트를 복제하지 않는다.
- 기간 탭 개수는 15px 이상, 28px 이상 배지로 표시한다. PC의 순서·복사 열은 고정하고 가운데 세 열은 같은 비율로 배분한다.
- 기본 기록 5개만 보인다. 펼치면 마지막 기록 아래에 접기 버튼이 나타나고, 접으면 원래 더 보기 문구로 돌아온다.
- `tools/check-article-presentation.mjs`가 전체 게임 글의 공통 렌더러·기록 보존·생성 테마 일치를 검사한다.
- `tools/run-layout-checks.mjs`가 전체 기간별 게임 글을 390px·1440px에서 검사한다. 숫자 배지, 표 정렬, 닫힌 기록 비노출, 펼치기·접기, 버튼·가로 넘침을 확인한다.
- Verify는 레이아웃 통과 후에만 검증 인증서를 발급한다. Publish Approved Article은 같은 SHA의 인증서를 재사용하거나 동일 검사를 실행하며, 실패 시 발행 단계로 진행하지 않는다.
- CSS·JS 변경은 생성 XML 두 파일에 반영한다. Worker 배포와 Blogger 테마 저장은 별개다. 테마 변경 시 최신 관리자 테마를 백업하고 관련 부분만 수정해 사이트 인증 등 운영 설정을 보존한다.
- 테마 저장 후 공개 페이지 PC·390px 실제 렌더링을 확인한다. CI 통과만으로 공개 테마 적용 완료를 보고하지 않는다.
