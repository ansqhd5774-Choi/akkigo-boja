# 홈 카테고리 목록

- 순서: 게임 / 유심·로밍 / 호스팅·도메인 / 해외직구 / 건강 / VPN / 교육.
- 각 카테고리는 한 줄이며 PC 6개, 중간 화면 3개, 모바일 4개씩 표시한다. 목록 양옆 화살표와 마우스 드래그·터치 스와이프로 넘긴다. 하단 페이지 번호 줄은 표시하지 않는다. 이동 상태는 카테고리별로 독립적이다.
- 전체 최근 글 피드로 카테고리 목록을 추정하지 않는다. `window.ncpFeed(category)`로 각 라벨의 공개 글을 읽는다. 한 카테고리 조회 실패는 해당 줄에만 안내한다.
- 공통 생성 소스는 `theme/home-r4.mjs`, `theme/home-r4.js`, `theme/home-r4.css`다. 변경 후 테마 생성·XML 검사·관련 테스트와 공개 PC·모바일 확인을 수행한다.
- 카테고리 이동은 제목 옆 화살표와 제목 링크로 제공한다. 별도 전체 보기 버튼은 표시하지 않는다. 모든 카드는 이미지 위 짧은 이름을 표시하는 공통 스타일이며 제목과 목록 간격은 6px이다. 목록 이동 화살표는 CSS 이중 화살표와 파란 배경을 사용한다.
