### 쿠폰 영역 결론
주요 문제는 2개:
1. 만료일 강조가 약함 — 현재 코드가 10월 6일 오전 9시 만료인데 보상과 같은 위계.
2. 복사 버튼의 시각적 우선순위가 다소 약함 — 경쟁 사이트는 코드 복사를 최우선 행동으로 둠.

수정 후보:
- 만료일에 날짜를 경고색이 아닌 중간 강조 수준으로 상향.
- 복사 버튼을 브랜드색 채우기 또는 코드영역 내부 primary-action 형태로 검토.
- 단, 공식 입력 CTA와 두 개의 primary 버튼이 경쟁하지 않게 하나만 강하게 보여야 함.
