시행일: 2026년 10월 5일

서비스와 Google 데이터 이용 목적

아끼고 보자는 공식 쿠폰 원천을 확인하고 Blogger 게시물을 관리하는 서비스입니다. Google OAuth 연결은 블로그 운영자의 게시물 조회·초안 생성·갱신·발행을 위해 사용합니다. 방문자의 Google 계정 연결을 요구하지 않습니다.

접근·저장하는 정보

운영자가 동의한 Blogger API 관리 권한으로 대상 블로그와 게시물 정보를 처리합니다. OAuth 인증정보와 갱신 토큰은 운영 Worker의 Secret에 저장합니다. 블로그 ID·게시물 ID·공개 주소·실행 상태는 운영 데이터베이스에 저장합니다. 프로그램의 게시물 관리 대상은 아끼고 보자 블로그로 제한하지만 Google 동의 화면의 권한 자체는 계정의 Blogger 관리 범위입니다.

전달과 공개

인증과 게시물 관리는 Google API를 사용하고, 서버 실행 및 인증정보 보관은 Cloudflare를 사용합니다. 게시물 제목·본문·공개 주소는 블로그 방문자에게 공개됩니다. 인증정보를 공개 게시물이나 GitHub 저장소에 넣지 않습니다. Google 사용자 데이터를 광고 타기팅이나 판매 목적으로 사용하지 않습니다.

보관과 권한 철회

연결을 유지하는 동안 인증정보를 보관합니다. 운영자는 Google 계정의 연결 관리에서 접근 권한을 철회할 수 있습니다. 운영 중단 시 운영자가 Worker Secret을 삭제합니다. 이미 공개한 게시물은 권한 철회만으로 삭제되지 않으며 Blogger에서 별도 관리합니다.

방문자와 문의

Blogger 방문, 댓글 및 플랫폼 쿠키는 Google의 정책도 적용됩니다. 개인 쿠폰, 계정 식별 정보나 CS Code를 댓글에 게시하지 마세요. OAuth 데이터 처리 문의는 Google 동의 화면에 표시된 사용자 지원 이메일로 보내주세요.

방문 통계

사이트 이용 현황과 정보 개선을 위해 네이버 애널리틱스를 사용합니다. 방문 페이지 주소, 이전 페이지 주소, 브라우저·기기 관련 정보와 쿠키를 이용한 방문 통계가 네이버 분석 서비스에서 처리될 수 있습니다. 이 통계는 개인 쿠폰 입력 성공을 확인하는 자료가 아닙니다.

검색어·계정 식별 정보가 담길 수 있는 쿼리 주소와 쿼리·해시가 있는 이전 페이지 주소에서는 분석 스크립트 실행을 건너뜁니다. m=0 또는 m=1만 있는 주소는 모바일 화면 구분용으로 허용합니다. 브라우저의 Global Privacy Control(GPC) 신호와 사이트 운영상 분석 제외 설정도 존중합니다. 이 제외 때문에 일부 방문이 통계에 누락될 수 있습니다.

네이버 분석 데이터의 처리·보관은 해당 서비스의 정책과 제공 설정에 따릅니다. 현재 별도의 보관 기간을 확인하지 못했으므로 임의의 기간을 안내하지 않습니다. 네이버 개인정보처리방침에서 제공자의 처리 기준을 확인할 수 있습니다. 쿠키를 차단해도 제공자 기준상 페이지뷰 등이 집계될 수 있으므로 쿠키 차단과 분석 전송 차단은 구분됩니다.
