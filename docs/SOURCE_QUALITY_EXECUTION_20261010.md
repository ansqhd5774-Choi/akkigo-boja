## 실행 결과
공개77글을 직접 HTTP 조회해 실패50URL의 실제 앵커를 대조했다. 45출처가29글에서 노출되며,최신 후보의 구조화 근거에 연결된 출처는2개다. 글 단위 링크를 모든 코드의 직접 근거로 임의 연결하지 않고 정확한 source URL이 일치하는 기록만 매핑했다.

## 우선 작업
- 브롤스타즈: SpaceMoney500은 ITSSUSHITIME/SAKURASPIKE!/BOBAPARTYYYY와 연결. 각 코드의 다른 원문도 있어 이 오류만으로 전체 후보를 만료 처리하지 않는다. 실제 공개 글 `qr-2026-10.html`.
- Z 루트: MrGuider403은 OKTOBER26/ZRTSML09와 연결. 일본판 성공 보고와 별도이므로403만으로 일본판 근거까지 무효화하지 않는다. 실제 공개 글 `z.html`.
- 운빨존많겜: danmaek404는 LUCKY111/222/333/444/555/666/888/999 후보와 연결. 현재도 공식 근거 미확인 표시. 실제 공개 글 `2026-10_0476929638.html`.
- 아쿠아랜드: TapTap404는 중국판11기록과 연결. 현재 사용 여부 미확인 표시. 실제 공개 글 `blog-post_479.html`.

404 두 원문 검색에서 동일 URL의 대체 결과가 확보되지 않았다. Wayback 조회는 웹 도구 접근 제한으로 미확인이다. 아카이브 부재로 단정하지 않으며 다른 홈페이지로 대체하지 않는다.
