# Official Source Selection Audit · 2026-10-05

## 원칙

- 공식 페이지 HTTP 200만으로 쿠폰 ACTIVE 처리 금지.
- 가격에 쿠폰/세일/회원할인이 혼합돼 있으면 개별 쿠폰 혜택으로 역산하지 않는다.
- 계정·앱 로그인 후에만 조건을 확인할 수 있으면 공개 원천만으로 ACTIVE 처리하지 않는다.
- 종료된/시즌이 지난 이벤트를 현재 원천으로 추가하지 않는다.

### 배달 플랫폼
- 현재 공개 웹에서 계정 비의존·조건 완결형 공식 쿠폰 원천을 확정하지 못함.
- 앱/계정별 혜택을 일반 공개 쿠폰처럼 자동 수집하지 않음.

## 다음 기준

쇼핑·배달 원천은 아래 필드를 공식 페이지에서 직접 구조화할 수 있을 때만 parserProfile을 부여한다.

- 혜택 유형/값
- 최소금액
- 최대할인
- 대상
- 앱/웹
- 시작/종료 또는 소진 조건
- 적용범위
- 중복 가능 여부
- 공식 출처

일부 필드가 불명확하면 후보 상태는 UNVERIFIED이며 ACTIVE로 자동 승격하지 않는다.
