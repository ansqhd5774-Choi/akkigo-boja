# 대표 로고 기준

- 공식 앱 아이콘이 이미 적용된 게임·유심 글은 유지한다.
- 상품 사진, 행사 배너, 강의 표지 대신 공식 사이트 헤더의 브랜드 로고를 사용한다.
- `data/representative-logos.json`에 원천 URL과 대표 이미지 URL을 기록한다.
- 정사각형 이미지 안에서 원본 비율을 보존한다. 홈 카드 제목과 겹치지 않도록 로고 영역을 상단에 배치한다.
- `tools/apply-representative-logos.mjs`로 카탈로그와 저장 원고를 동기화한다.
- 초안 검증과 실제 발행은 등록된 대표 로고가 첫 이미지인지 검사한다.
- 이번 변경: 기존 브랜드 글 27개 및 포트블록스 게임 1개. 제목, 쿠폰, 날짜, 출처 본문은 변경하지 않았다.

검증: 전체 테스트 443개 통과, DOM 정책 통과, Worker dry-run 및 XML 검증 통과. 실제 발행 및 공개 화면 검증은 발행 결과로 별도 확인한다.
