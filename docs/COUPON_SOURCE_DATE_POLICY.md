# 쿠폰 발행 날짜 기록 규칙 — 2026-10-09

## 대상
아끼고 보자 Blogger 쿠폰 수집 전반. 다른 티스토리 블로그나 Blogger 테마 발행일에는 자동 적용하지 않는다.

## 필수 원칙
1. 쿠폰 항목의 `publishedAt`은 **수집한 쿠폰 출처 글의 작성·최초 게시일**로 기록한다. 원본 발급사의 해당 쿠폰 공지가 있다면 그 공지의 게시 날짜를 최우선 사용한다.
2. `sourcePublishedAt`에는 같은 원문 날짜를 저장하고, `dateBasis`에 출처 종류와 원문 확인 수준을 명시한다.
3. `sourceCheckedAt`은 정보를 다시 읽은 날짜이며 발행일로 바꾸지 않는다.
4. `expiresAt` / `expiresAtKST`는 쿠폰의 사용 종료 시각이며 발행 날짜로 바꾸지 않는다.
5. 원본 공지의 최초 게시 날짜를 알 수 없으면 재확인일·사이트 갱신일을 발행 날짜로 추측하지 않는다. 외부 글의 게시일을 기록했다면 해당 글의 게시일임을 반드시 표시하고 공식 발급일로 혼동하지 않는다.
6. 언론·블로그·영상이 옛 쿠폰을 재소개해도 발급사 원문 게시일이 확인되면 그것을 보존한다. 원문이 없다면 확인된 개별 출처 글의 게시 날짜로 기록하되 해당 제3자 출처를 함께 기재한다.
7. 동일 게임의 해외 표기는 독립적인 신코드라고 간주하지 않는다. 코드 문자열, 게임명, 발행 채널, 사용 서버를 비교한다.
8. 게시일이 다른 기록과 충돌하면 공식 발급사 1차 원문을 우선하고 `dateConflict`를 기록한다. 근거 없이 날짜를 변경하지 않는다.
9. 새 쿠폰 데이터를 추가하더라도 공식 보상, 실제 사용 성공, 만료 상태를 임의로 승격하지 않는다.
10. Blogger 원고 자체의 생성·수정·공개 날짜는 별도 운영 메타데이터다. 쿠폰 출처의 `publishedAt` 필드가 Blogger 게시물 타임스탬프를 소급 수정하는 근거가 아니다.

## 적용 범위
신규 수집 자료와 향후 쿠폰 글 작성 시 위 규칙을 사용한다. 기존 게시물 postId/URL, 테마, 자동 발행 조건을 이 문서 때문에 변경하지 않는다.
