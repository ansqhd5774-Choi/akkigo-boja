# 아끼고 보자 라벨·SEO 운영 규칙 R1 — 2026-10-08

## 범위
- Blogger `lsifl.blogspot.com` 전용. Tistory 프로젝트·기타 블로그 변경 금지.
- Blogger 관리자 라벨과 17개/현재 운영 분류 URL, 기존 게시물 URL 및 postId 유지.
- 공개 게시물의 라벨 칩은 native Blog `postLabels` 출력에서만 숨김. 분류 링크와 실제 라벨은 삭제하지 않음.
- Blogger 테마는 별도 관리자 저장 후에만 공개 적용으로 인정.

## 신규 글 라벨
- 2~4개 권장, 필수: 사이트 카테고리 1개 + 정확한 게임·브랜드명 1개.
- 공식 영문명은 이용자 구별에 도움이 되고 중복 분류가 아니라면 1개 허용.
- 쿠폰 유형·혜택은 실제 본문에서 다루며 공통 탐색에 도움될 때만 1개 허용.
- 연월, 활성 상태, 검증 상태, 키워드 변형(띄어쓰기 포함), 길고 중복된 문구는 라벨로 만들지 않음.
- 기존 라벨 일괄 정리·삭제는 별도 승인 전 금지.

## 검색 의도별 키워드와 제목
- 글당 관련 검색어 후보 8~15개를 조사하되 고정 개수로 본문 반복하지 않음. 경쟁·수요의 수치가 없다면 추측하지 않음.
- 사용자 검색 의도(현재 코드/과거 코드/사용법/보상/문제 해결)별로 적합한 h2·h3, 실제 내용과 링크에 자연스럽게 반영.
- 게임 쿠폰 글 제목은 게임명만 단독 표기; 영문·월·코드·쿠폰 검색어는 본문과 검색 설명에 반영.
- 설명에는 발행 시점, 검증 상태, 실제 수집 개수 및 주요 혜택만 작성. 검색엔진 스니펫은 달라질 수 있음.
- `meta keywords` 사용 금지, 숨겨진 키워드·키워드 반복 스팸 금지.
- 공식 원천과 수집 시점·실제 사용 성공을 구분. 미검증 문자열을 ACTIVE로 승격하지 않음.

## 발행 및 검증
- 새 게임글은 라벨과 검색 설명·검색 의도별 섹션을 편집 체크리스트로 확인.
- 공개 UI 변경 시: Blogger 현행 테마 비공개 백업 → XML 검사 → 공식 HTML 편집기 1회 저장 → 상세 화면/카테고리 PC1440·mobile390 검증.
- 공개 상세 페이지에서 라벨 칩이 안 보이면서 게임 분류 링크와 게시글 내용, URL이 유지되는지 확인.
- Search Console의 검색어별 노출·클릭·CTR·평균 순위를 동일 기간과 검색 의도 기준으로 비교; 상승 보장 금지.
