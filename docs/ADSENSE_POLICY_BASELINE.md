# AdSense 화면별 기준

- 공개 글(`data:view.isPost`)만 광고 실행 허용. 홈·검색·카테고리·오류·고정 안내 페이지는 광고 실행 제외.
- Blogger 공통 광고 로더는 테마 광고 위젯과 별도로 자동 삽입된다. 로더 존재만으로 광고 노출이나 정책 위반을 확정하지 않는다.
- 비글 화면은 head 첫머리의 CSP script-src로 허용된 자체/Blogger/분석 스크립트만 실행한다. 신규 스크립트 도입 시 허용 출처와 화면별 영향을 검토한다. 광고 출처는 허용하지 않는다.
- 글에는 이 제한을 적용하지 않아 심사·광고 로더를 유지한다. 자동 광고는 현재 OFF이며, 추후 ON 전 탐색/빈 화면 제외 상태를 재검증한다.
- 기본 Blogger all-head-content, canonical, robots, 검색 설명은 유지한다.
- 홈에는 기본 이용 안내·혜택 유형 구분·실제 글 링크를 출력한다. 카테고리에는 Blogger가 직접 출력하는 최근 글 제목·본문 요약 4개를 제공한다. JavaScript/외부 피드 실패 시에도 이 콘텐츠는 유지한다.
- 게임 카드의 수치는 '기록'이며 현재 유효 개수를 뜻하지 않는다. 비게임의 코드 0개는 '혜택 안내'로 표현한다.
- 빌드는 tools/adsense-policy-theme.mjs를 적용한다. 운영 테마 수동 수정 시 최신 운영본을 먼저 백업하고 동일 변환을 적용한다. 오래된 생성본으로 전체 교체하지 않는다.
- 필수 검증: XML, 정책 회귀검사, 기본 테스트, 공개 홈·카테고리·실제 글·빈 검색·404의 콘텐츠/광고 실행, PC·390px 렌더링. 로더 수 대신 광고 요청 iframe·광고 요소·실제 화면을 구분한다.
- 수정·저장·공개 검증·재심사 제출·승인은 별도 상태다. 검토 요청 접수는 승인 완료가 아니다.
