Pokémon Night Out Twitch Drop

한국시간 2026년 10월 25일 오전 11시 30분부터 진행되는 공식 Pokémon Twitch 방송을 30분 시청하면 개별 Timed Research 코드를 받을 수 있습니다.

보상: Timed Research 완료 시 Pokémon Night Out 야구 저지 아바타 아이템

받는 순서: Pokémon Trainer Central 계정과 Twitch 연결 → 방송 30분 시청 → Twitch Drop 수령 → rewards.pokemon.com에서 코드 확인 → Pokémon GO Web Store에서 입력

이 코드는 아직 공개된 공용 코드가 아니라 방송 시청 후 계정별로 받는 코드입니다. 현재 글에는 존재하지 않는 코드를 임의로 넣지 않았습니다.

  • 이미 같은 코드를 사용한 계정인지 확인하세요.

자주 묻는 질문

2026년 10월 Pokémon GO에서 공식 확인되는 코드는 무엇인가요?

ADIDASxPOKEMON은 Pokémon GO 공식 공지에서 직접 확인됩니다. adidas 신발 아바타 아이템을 받을 수 있고 2027년 1월 15일까지 사용할 수 있습니다.

LEGOxPOKEMONGOxBERRIES 보상은 무엇인가요?

몬스터볼 10개, 라즈열매 5개, 파인열매 5개, 나나열매 5개입니다. 별도의 공식 종료일은 확인되지 않았습니다.

Pokémon GO 앱 안에서 코드를 입력할 수 있나요?

현재는 Pokémon GO Web Store의 Code Redemption 페이지에서 로그인한 뒤 코드를 입력하는 방식이 기본입니다.

Pokémon Night Out 코드는 지금 입력할 수 있나요?

아직 아닙니다. 10월 24일 미국 방송을 30분 시청한 뒤 Twitch Drop으로 받는 개별 코드입니다. 한국시간으로는 10월 25일 오전 11시 30분부터 방송이 시작됩니다.
