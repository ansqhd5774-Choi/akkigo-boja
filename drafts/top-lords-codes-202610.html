탑 로드 쿠폰 입력 방법

제3자 쿠폰 사이트는 아바타·프로필 → 설정 → Redeem Code 경로를 안내하고 있습니다. 다만 공식 게임 내 화면에서 해당 입력 메뉴를 직접 확인하지 못했으므로 아래는 확인 절차입니다.

  1. 탑 로드 최신 버전을 실행하고 본인 서버에 로그인합니다.
  2. 프로필·설정·이벤트 메뉴에서 쿠폰 / 기프트코드 / Redeem Code 입력란이 있는지 확인합니다.
  3. 입력란이 있으면 위 표의 복사 버튼을 눌러 대소문자를 그대로 입력합니다.
  4. 교환 실패 시 보상 우편·재입력 기록·지역 제한 여부를 확인합니다. 메뉴가 없으면 공식 게임 내 고객센터에서 문의합니다.

공식 고객지원 연락처: topking-support@gamespark.net. 공식 앱의 내 프로필 → 설정 → 고객센터 경로가 Google Play 개발사 답변에서 확인됩니다. 쿠폰 메뉴의 존재와는 별개입니다.

탑 로드 쿠폰이 작동하지 않는 경우

  1. 영문 대소문자와 숫자 0/O, 1/I 혼동을 확인합니다.
  2. 같은 코드를 계정에서 이미 사용했는지, 서버·국가가 제한되는지 확인합니다.
  3. 타 게임에도 쓰이는 범용 코드인지 확인합니다. 범용 코드라는 이유만으로 사용 불가를 확정하지는 않습니다.
  4. 사이트의 '작동 중' 표기만 존재하고 공식 발급 근거가 없다면 사용 실패 가능성이 있습니다.

한 계정의 성공 또는 실패를 전체 이용자에게 일반화하지 않습니다. 계정 비밀번호·OTP·결제정보 입력을 요구하는 외부 페이지는 사용하지 마세요.

공식 스토어 혜택과 쿠폰의 차이

탑 로드 공식 스토어에는 게임 UID를 입력해 금괴를 구매할 때 5% 추가 금괴를 제공한다는 안내가 있습니다. 이는 무료 쿠폰이나 교환코드가 아닌 유료 구매 혜택이므로 위 쿠폰 목록에 포함하지 않았습니다.

다른 게임의 쿠폰과 구분하기

Top Lords(탑 로드)와 Lords Mobile(로드 모바일)은 서로 다른 게임입니다. LM...으로 시작하는 로드 모바일 코드를 탑 로드 쿠폰으로 혼동하지 마세요. 일부 국내 게시물의 'Top Road Game' 표기 역시 앱 패키지·운영사 동일성이 확인되지 않았으므로 별도로 구분합니다.
