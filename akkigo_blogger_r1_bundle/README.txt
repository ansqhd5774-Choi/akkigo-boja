AKKIGO BOJA BLOGGER R1 BUNDLE

이 패키지는 기존 Tistory용 쿠폰 UI/운영 자료를 Google Blogger용으로 변환한 1차 패키지입니다.

폴더
- theme/
  - blogger-theme-r1.xml                : Blogger 테마 배포 초안
  - coupon-ui-r3-blogger.css            : 개발용 CSS 분리본
  - coupon-ui-r3-blogger.js             : 개발용 JS 분리본
- article/
  - coupon-article-r3-blogger.html       : Blogger 게시물 HTML/renderer 출력 템플릿
- docs/
  - CATEGORY_STANDARD_1_BLOGGER.txt
  - BENCHMARK_DIRECTION_R1_BLOGGER.txt
  - BLOGGER_PLATFORM_STANDARD_R1.txt
  - TISTORY_TO_BLOGGER_MIGRATION_MAP_R1.txt

중요
1. blogger-theme-r1.xml은 Google Blogger Theme > Edit HTML/Restore에 맞춘 starter theme입니다.
2. 실제 블로그 생성 후 blogId와 OAuth 발행 환경은 별도 연결해야 합니다.
3. 기존 Tistory 영양 글은 이 패키지에서 삭제/이전하지 않습니다.
4. 쿠폰 브랜드 허브는 Blogger postId를 장기 유지하는 방식으로 업데이트합니다.
5. 현재 패키지는 디자인/플랫폼 변환본이며 실제 Blogger 공개 발행 완료본은 아닙니다.
