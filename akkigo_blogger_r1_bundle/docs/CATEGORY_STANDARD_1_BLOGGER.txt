상태: ACTIVE
플랫폼: Google Blogger
작성 기준일: 2026-10-05

1. 기본 원칙
- 한국 사용자 대상 검증형 쿠폰 DB를 운영한다.
- 카테고리는 산업 규모가 아니라 쿠폰 사용 필요성, 혜택 체감도, 반복 검색, 구조화 적합성, 국내 수요를 우선한다.
- 기본 콘텐츠 단위는 브랜드 또는 게임별 통합 쿠폰 페이지다.
- 쿠폰 하나마다 글을 대량 생성하지 않는다.
- 해외직구는 산업 카테고리가 아니라 필터/허브로 처리한다.
- 동일 브랜드/게임은 Blogger postId를 장기 자산으로 유지하고 같은 postId를 업데이트한다.
- 월별 쿠폰 글을 반복 신규 생성하지 않는다.
- 기존 Tistory 영양 콘텐츠는 별도 승인 없이 삭제·덮어쓰기·리디렉션하지 않는다.
- Tistory 숫자 URL은 Blogger로 그대로 이전될 수 없으므로 레거시 자산으로 취급한다.

5. Blogger 매핑
- 대분류 → Blogger Label
- 브랜드/게임 허브 → 단일 Blogger Post
- 상태/조건 → 본문 JSON/HTML + 필요시 Label 보조
- 동일 허브 업데이트 → Blogger API posts.update 또는 posts.patch
- 신규 허브 생성 → Blogger API posts.insert
