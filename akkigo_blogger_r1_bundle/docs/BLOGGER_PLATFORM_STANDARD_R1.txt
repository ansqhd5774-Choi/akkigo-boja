AKKIGO BOJA BLOGGER PLATFORM STANDARD R1

상태: ACTIVE
플랫폼 전환: Tistory → Google Blogger
기준일: 2026-10-05

1. Source of truth
- GitHub 저장소에서 coupon JSON, renderer, validator, Blogger theme XML, publish state를 관리한다.
- Blogger 관리자 화면에서만 수정하고 GitHub에 반영하지 않는 상태를 장기간 허용하지 않는다.

2. Theme
- 기본 파일: theme/blogger-theme-r1.xml
- 개발 분리본: theme/coupon-ui-r3-blogger.css, theme/coupon-ui-r3-blogger.js
- Blogger 업로드/HTML 편집 시 XML 단일 파일이 배포본이다.
- HTML/CSS 변경 전 테마 백업을 먼저 저장한다.

3. Blogger API
- 신규 게시물: posts.insert
- 기존 게시물 전체 수정: posts.update
- 부분 수정: posts.patch
- 장기 브랜드 허브는 동일 postId 유지.
- 자동화는 OAuth 권한을 사용하고 비밀번호/OTP 자동입력 방식에 의존하지 않는다.

4. URL 정책
- Blogger의 postId를 내부 영구 식별자로 저장한다.
- 공개 URL은 발행 결과를 state에 저장한다.
- 동일 브랜드/게임 허브는 가능한 한 기존 postId를 업데이트한다.
- Tistory 숫자 URL과 Blogger URL은 동일 자산으로 간주하지 않는다.
- 기존 Tistory 콘텐츠는 별도 마이그레이션 결정 전까지 유지한다.

5. Labels
Blogger Label을 카테고리/탐색에 활용한다.
대분류 17개는 기준1을 따른다.
조건 태그를 과도하게 Label로 만들지 말고, 쿠폰 조건은 구조화 JSON과 본문 data-*에 보관한다.

6. Verification
- source checked time와 working verified time 분리.
- ACTIVE는 허용된 근거가 있어야 한다.
- 공개 후 익명 페이지에서 title/body/code/status/conditions/CTA를 검증한다.
- PC 1440 / mobile 390 overflow 0을 목표로 한다.

7. HTTPS / Domain
- blogspot.com 주소는 HTTPS를 사용한다.
- 맞춤 도메인 사용 시 Blogger 설정에서 HTTPS와 HTTPS redirect를 활성화한다.
- 도메인은 플랫폼 전환과 별개의 결정으로 관리한다.

- [##_..._##] 치환자

- Tistory 전용 Chrome profile
- Tistory 대표이미지/kakaocdn 검증
